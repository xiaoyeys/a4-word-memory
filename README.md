# A4词忆

基于“A4 纸随机位置回忆法”的本地优先背单词 Web App / PWA。

A4词忆把“背诵、拼写、空间位置和主动回忆”放进同一个学习流程：先记住单词，再完成拼写，把单词放到 A4 纸的随机位置；每完成一批单词，按纸面上的书写顺序回忆释义。学习记录、词库、复习排程和记忆纸默认只保存在当前设备，不需要注册或服务器。

## 核心功能

### A4 空间记忆学习

- 每个单词先完成自定义遍数的主动背诵，再进入拼写。
- 拼写正确后，将单词手动放到 A4 纸的任意空白位置，或使用自动随机放置。
- 单词位置使用与屏幕无关的逻辑坐标保存，桌面端、平板端和手机端保持一致。
- 按书写顺序进行累积回忆，错误顺序不会直接泄露答案。
- 回忆时支持“记得 / 模糊 / 忘记”三档评价。
- 忘记的单词可以立即重学，保留原来的纸面位置和放置顺序。
- 支持多页 A4 纸、分页查看、缩放和手机端触控操作。

### 本地计划与智能复习

- 首页显示今日完成状态、连续学习天数和当月打卡日历。
- 每日新词目标可以自定义，已到期复习词会自动加入今日计划。
- 复习队列优先处理到期词、薄弱词和长期未复习词。
- 首页展示未来 7 天的预计复习量。
- 过期复习不会丢失，会继续保留在待复习队列中。
- 可选择今日计划、仅复习、薄弱加练或自由学习。

### 薄弱词专区

- 按拼写错误、忘记次数、模糊次数筛选。
- 支持标记“重点词”和“易混淆词”。
- 一键开始薄弱词 A4 复习。
- 统计页显示单词难度、下次复习时间和长期表现。

### 词库管理

- 内置小学课标、中考、高考、四六级、考研及出国考试词书，也支持创建自定义词库。
- 支持 TXT、CSV、XLSX、JSON 和文本粘贴导入。
- 导入前预览字段、重复项和错误行，确认后才写入本地数据。
- 只输入英文单词时，可以从内置词库自动匹配音标、词性和释义。
- 支持词库搜索、词条搜索、新增、编辑、删除、重命名和排序。
- 自定义词库与学习记录均保存在浏览器 IndexedDB。

### 记忆纸档案

- 学习完成后自动保存历史 A4 记忆纸。
- 可以按词书、日期、名称和文件夹搜索。
- 支持收藏、重命名、移动到自定义文件夹和删除档案。
- 点击历史纸上的单词即可查看完整词卡和发音。
- 显示首轮记忆率和最终掌握率。
- 支持导出 SVG 图片和浏览器打印。

### 个性化学习体验

- 自定义每个单词的背诵遍数。
- 自定义每完成多少词进入一次累积回忆。
- A4 纸支持素纸、方格和横线样式。
- 可分别显示或隐藏音标、词性和释义。
- 自动朗读开关、朗读口音和浏览器回退朗读速度。
- 学习页支持键盘快捷键：
  - `Space`：完成当前一遍背诵；
  - `R`：重新播放当前单词；
  - `1`：记得；`2`：模糊；`3`：忘记。

### PWA 与数据安全

- 支持添加到手机桌面或电脑应用列表。
- 首次在线加载后，应用外壳和本地学习功能可以离线使用。
- 断网状态会在设置页显示，在线发音不可用时自动尝试浏览器语音。
- 检测到新版本时提示更新，不会在学习过程中强制刷新。
- 支持完整备份和恢复，恢复前自动下载当前数据恢复点。
- 备份文件包含词库、学习记录、复习排程、未完成学习和设置。
- 不上传词表、释义、拼写输入或学习历史。

## 学习流程

```text
选择词书和学习计划
        ↓
背当前单词若干遍
        ↓
正确拼写
        ↓
放置到 A4 纸
        ↓
达到回忆批次后按顺序回忆整张纸
        ↓
评价记忆结果并进入下一个单词
        ↓
完成本轮，更新 FSRS 复习排程
```

## 本地运行

环境要求：Node.js 18 或更高版本。

```bash
git clone https://github.com/xiaoyeys/a4-word-memory.git
cd a4-word-memory
npm install
npm run dev
```

Vite 会输出本地地址，通常是：

```text
http://localhost:5173/
```

局域网内用手机访问时，可以使用 Vite 输出的 Network 地址。电脑和手机需要连接同一个局域网。

## Netlify 部署

仓库根目录包含 `netlify.toml`，配置如下：

- Build command：`npm run build`
- Publish directory：`dist`
- 单页应用回退到 `index.html`

将 Netlify 项目连接到 GitHub 仓库的 `main` 分支后，每次推送都会自动触发部署。部署失败时优先检查 Node.js 版本、构建日志和 `dist` 发布目录。

## 数据与隐私

应用使用以下本地存储：

- IndexedDB：词库、词条、学习轮次、复习卡片、记忆纸和备份相关数据；
- localStorage：少量界面偏好，例如侧边栏状态和学习面板位置；
- Service Worker Cache：PWA 应用壳和静态资源。

清除浏览器站点数据会删除当前设备上的学习记录。建议完成第一轮学习后，在“设置 → 本地数据”导出备份。更换设备时，可在新设备中导入备份文件。

在线发音使用有道词典音频地址；如果网络或浏览器阻止在线音频，会回退到 Web Speech API。音频服务不影响本地学习记录和核心学习流程。

## 内置词库与版权

内置词库文件位于 `public/vocabularies/`。应用启动时只读取词书目录，用户选定计划词书后才会按需加载该词书并保存到浏览器 IndexedDB。词库来源、许可证和版权说明见：

- `public/vocabularies/NOTICE.md`
- `public/vocabularies/LICENSE`

小学词书的 505 个词目取自教育部《义务教育英语课程标准（2022年版）》附录 3“二级词汇表”；音标、词性和中文释义以及其他词书数据由 [ECDICT](https://github.com/skywind3000/ECDICT) 派生，相关数据遵循其许可证。考试名称和商标归各自权利人所有，本项目仅作为个人学习工具使用。

## 开发说明

- 复习排程使用 `ts-fsrs`，不在项目中自行实现间隔重复公式。
- 结构化数据使用 Dexie 封装 IndexedDB。
- Excel 导入使用 `read-excel-file`，只解析单元格值，不执行宏。
- 图表使用 Recharts，页面按需加载统计、词库和档案模块。
- 朗读优先尝试在线音频，失败后回退到浏览器本地语音。
- 所有动态词库内容以文本方式渲染，不执行导入文件中的脚本。

## 已知限制

- 不同手机浏览器对 Web Speech API 和自动播放策略支持不一致，首次朗读可能需要用户先点击一次页面。
- 浏览器通知属于本地页面通知；关闭浏览器或系统禁止通知时，无法保证后台提醒。
- 当前没有账号体系、云同步和跨设备自动合并。
- 清除浏览器站点数据前必须先导出备份。
